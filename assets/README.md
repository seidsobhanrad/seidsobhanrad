# Profile artwork

This directory contains two original, self-contained SVGs used by the profile README:

- `banner.svg` is the 3:1 dark-futurist hero artwork. It carries the Sobhan Rad wordmark and “Build what comes next” line.
- `footer.svg` is a minimal cyan-to-violet orbital accent used above the closing line.

## Editing

Both files use a `1500 × 500` or `1200 × 84` viewBox, explicit dimensions, simple SVG shapes, and built-in gradients. They have no scripts, embedded HTML, external fonts, or remote resources. Edit the SVG text and geometry directly; preserve the `<title>`, `<desc>`, `viewBox`, and `xmlns` so the graphics remain accessible and portable.

The palette references the profile direction: deep charcoal `#0D1117`, cool text `#E6EDF3` / `#9DA7B3`, electric cyan `#00F7FF`, and violet `#8A2BE2`. GitHub controls the README page's own colors and typography. These assets have not been visually rendered in GitHub; if an SVG is not displayed by a client, remove the image and retain the surrounding Markdown name and tagline as the graceful fallback.
